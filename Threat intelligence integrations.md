Overview
The VirusTotal integration enhances security operations by automating the enrichment of suspicious files, URLs, and IPs with actionable intelligence via the CrowdStrike Falcon® platform. This integration provides real-time insights to detect, investigate, and respond to potential threats efficiently. With Falcon® Fusion SOAR workflows, teams can leverage VirusTotal data to streamline security investigations, improve alert triage, and reduce time-to-response by correlating threat intelligence across multiple sources.

Accelerate Threat Detection: Automate enrichment for files, URLs, and IPs to identify malicious activities faster.
Streamline Investigations: Leverage real-time threat context to improve triage and response times.
Correlate Intelligence Sources: Integrate VirusTotal data with Falcon alerts to enhance security workflows.
Improve Operational Efficiency: Automate workflows through Falcon Fusion SOAR to reduce manual efforts and focus on high-priority threats.
Configuration Instructions
Create a VirusTotal Account:
Visit virustotal.com.
Click Join our community and complete the registration process by entering the required details.
Obtain API Key:
Log in to your VirusTotal account.
Click your username in the top right corner and select My API key.screenshot of VirusTotal dashboard 
Copy the API key from this page. Store it securely since it will be needed in the Fusion SOAR configuration.
IP Allowlist Configuration (if applicable):
If your organization uses IP allowlists, ensure the IP addresses used for API requests are allowed.
In Fusion SOAR, Paste the API key from VirusTotal
Save the configuration and test the integration to ensure it works correctly.
Reference Documentation
For more details on VirusTotal API setup, refer to the official documentation: VirusTotal API Documentation

Integrating with Falcon Platform
VirusTotal integrates into Falcon platform and Falcon Fusion to provide the most relevant and rich contextual information for any suspicious indicators across endpoint telemetry. The data provided includes anti-virus detection ratio, threat label and category, submission uniqueness , number of submitters, crowdsourced YARA matches, and other valuable details. Get all the actionable data you need for any observable and use it to quickly pivot into the VirusTotal website to find related artefacts and indicators to help enrich incident response workflows
